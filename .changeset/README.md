# Changesets

Welcome to Changesets! This directory stores changesets generated by developers before committing changes to packages.

## Workflow

1. Modify code in packages or apps.
2. Run `pnpm changeset`.
3. Choose the packages that changed and whether it's a `major`, `minor`, or `patch`.
4. Provide a summary of the change.
5. Commit the generated markdown file.
6. When releasing, run `pnpm changeset version` to bump versions and update changelogs, followed by `pnpm changeset publish`.
